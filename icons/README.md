# Icon direction

The chosen direction is **option 2** from the initial design discussion:

> A recognizable Klingon trefoil motif integrated into a custom dark metallic plate.

Target character: 24th-century Klingon, restrained rather than neon/gamer-styled.

Provisional palette:

- charcoal / near-black structure
- dark graphite metal
- restrained Klingon red
- aged bronze / gunmetal accents
- warm light text where required

Final artwork will be created deliberately before publication rather than silently substituted with a generic icon.
