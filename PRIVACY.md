# Privacy

Klingon Translator is designed to work locally in Firefox.

## Data collection

**None.**

The extension does not collect, transmit, sell, share, or store browsing history, page content, typed translation text, identifiers, analytics, telemetry, or personal information on a remote service.

## Permissions

Klingon Translator requests only:

- `activeTab` — temporary access to the tab the user explicitly activates the extension on.
- `scripting` — used to inject the local floating translator interface and translation engine into that active tab.

The extension does not request permanent access to all websites.

## Network activity

The default translation engine does not make network requests. EN-US / PT-BR analysis and tlhIngan Hol generation run locally.

## Future features

If an optional external translation provider is ever added, it must remain disabled by default and its data handling must be disclosed separately before release.

Last updated for version 0.0.4.
